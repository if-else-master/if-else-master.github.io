新興科技教育遠距示範服務計畫工讀

高中打工仔：服務學習

📋 前言

這學期我接了台北市數位實驗高級中等學校的「新興科技教育遠距示範服務計劃工讀生」，主要負責學校的無障礙網頁設計、新興科技教育展協辦、展覽個人專案等。

無障礙網頁

由於我們學校的網站框架沒有完整的無障礙功能，沒有符合無障礙標章的Ａ級標準，因此這次工讀的第一項工作就是將網站改成無障礙。A級的無障礙功能相對簡單，將超連結的加上標註，讓視障者將滑鼠移動到連結上的時候可以聽見該連結的目的地。接下來是圖片的 alt 標註，我利用 Python 寫了一個爬蟲，將校網上的圖片都爬出來，接下來就是苦力活，一張一張圖片加上 alt 標註。最後是將複雜的圖片用 CSS 呈現，這樣視障者才可以使用滑鼠去拖啦文字並聽取內容，而圖片的 alt 規定只能寫75字，這可能沒辦法完整的說明圖片內容。

總結以下內容：
1.針對網站進行 A 級無障礙標準改版

  • 因學校網站原本不符合無障礙標章 A 級標準，因此將此作為改版的首要任務。

2.超連結標註

  • 為網站上的所有超連結加上輔助說明文字（ARIA label 或 title 屬性）。
  • 讓視障者能透過螢幕閱讀器知道連結的目的地。

3.圖片加上 alt 標註

  • 使用 Python 撰寫爬蟲程式，將校網上的所有圖片批次抓取出來。
  • 為每一張圖片逐一撰寫 alt 屬性說明，以協助視障者理解圖片內容。
  • 注意 alt 說明需控制在 75 字以內，避免違規。

4.將複雜圖片轉為 CSS 呈現
-將原本以圖像方式呈現的複雜資訊（如流程圖、圖表等），改用 HTML + CSS 架構重建。
-讓使用者能夠選取拖曳其中的文字，並透過螢幕閱讀器朗讀內容。

新興科技教育展：松菸

這次的工讀內容是協助老師在新興科技教育展擺攤，地點在松菸，那我也想藉此機會分享我個人的專案：「深度影片翻譯服務」，擺攤的時候這個專案還沒有那麼完整，正處於開發中狀態，那因為過程中會遇到很多相關專業的老師，想藉次機會請教幾個問題。


高雄科工館-新興科技嘉年華

下一站高雄科工館，由於這次的活動受眾年齡偏小，所以我帶了很多3D小玩具，並陪和中山女高的老師進行現場互動教學，那如果遇對我的專題有興趣的我也會跟他們介紹。


心得

總結這學期的工讀經驗，主要參與了無障礙網站的建置、個人專題的開發，以及協助校內活動擺攤。其中，無障礙網站算是這學期的主軸工作之一。在完成初期架構後，因應老師安排我負責擺攤與專題發表的任務，網站後續的維護便交接給學弟處理，也算是一場學長與學弟之間的協作經驗。
進入學期後半段，工作的重心轉向個人專題的開發與校內展示活動。準確來說，我是以工讀生的身份，將原本就持續開發的專案進行延伸並公開發表。這次的展示對象主要是老師們，因此我還特別準備了比較專業的講解內容。雖然過程中發生了不少有趣的小插曲，但整體而言是一段既充實又有趣的經歷。
